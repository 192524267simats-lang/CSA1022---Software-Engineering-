# Team repository workflow
1. Create a GitHub repository and add collaborators.
2. Protect `main`; require pull-request review.
3. Create one branch per module (e.g. `feature-auth`, `feature-catalog`).
4. Commit small, descriptive changes.
5. Open a pull request and request review.
6. Resolve review comments and merge after checks pass.
7. If conflicts occur, update from main, resolve locally, test and push.
8. Record branch, PR, reviewer and merge result in this file.
